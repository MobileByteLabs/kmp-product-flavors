## Architectural commitments (from RFC §1.1, NON-BYPASSABLE)

1. **Zero-touch adoption** — consumer's per-module `build.gradle.kts` files are byte-identical between v1.x and v2.0; the plugin owns the entire matrix internally.
2. **No per-module `compilations { create("freeDev") { … } }` blocks** in consumer KMP files on ANY target. The D1 spike and the Q4 iOS probe used these as proof artifacts only.
3. **Single-point opt-in** — `gradle.properties: kmpFlavors.buildMatrix=true` OR `buildMatrix.set(true)` in the convention plugin. Hybrid resolution (gradle.properties default + extension override).
